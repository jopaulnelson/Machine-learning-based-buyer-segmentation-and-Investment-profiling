# Real Estate Buyer Segmentation Dashboard

This project provides an end-to-end machine learning pipeline for buyer segmentation in the real estate domain, with an interactive Streamlit dashboard.

## Features
- Data loading and cleaning
- Exploratory Data Analysis (EDA)
- Feature engineering
- Clustering with K-Means and Hierarchical methods
- Optimal cluster determination
- Visualizations
- Interactive filters and KPI cards
- Save and load models
- Downloadable reports
